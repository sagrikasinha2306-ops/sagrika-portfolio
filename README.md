# Sagrika Sinha Portfolio

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy on Vercel
1. Create a GitHub repository.
2. Upload all files in this folder.
3. Import the repository into Vercel.
4. For this static HTML project, no build command is required.
5. Deploy.

## Before publishing
Replace the placeholder LinkedIn and Behance URLs in `index.html` with your real profile URLs.
Replace the cropped project/profile images in `assets/` with your original high-resolution images for a sharper portfolio.
